# PHP SSE

PHP SSE consumes Server-Sent Events (SSE) streams with Guzzle, yielding each event as the server
sends it.

```bash
composer require hosmelq/sse
```

Read the [full documentation](https://hosmelq.com/docs/sse-php).

## Development

Run the test suite with:

```bash
composer test
```
